# Enes Kavak

Siber güvenlik ve OT güvenliği üzerine çalışıyorum, öğreniyorum ve küçük projeler geliştiriyorum.

## İlgi alanlarım

- OT / endüstriyel ağ güvenliği, IEC 62443 kavramları (zone, conduit, güvenlik seviyeleri)
- Ağ trafiği analizi ve saldırı tespiti
- Güvenli yazılım geliştirme
- Python

## Projeler

- **[Layer 4 Defense Lab](https://github.com/eneskavakk/layer4-detector)**: PCAP trafiğinde kural tabanlı ve ML destekli saldırı tespitinin karşılaştırması
- **[CyberShield](https://github.com/eneskavakk/cybershield)**: Parola güvenliği ve sızıntı kontrolü
- **[RSA Lab](https://github.com/eneskavakk/rsa-dashboard)**: RSA'nın Python ile sıfırdan uygulanışı
- **PortAtlas**: Fabrika ağı bağlantı kaydı ve OT güvenlik takibi (şu an özel repo)

Güvenlik dışında birkaç makine öğrenmesi çalışmam da var: [AIHR](https://github.com/eneskavakk/AIHR), [Heart-Attack-Prob](https://github.com/eneskavakk/Heart-Attack-Prob).
